# Autoportonager Engine (Backend)

Plataforma de trading e inversión automatizada por estrategias algorítmicas.

## Stack
- Python 3.12 / Django 5.2 LTS + DRF
- Celery + Redis
- SQLite (Local) / PostgreSQL 16 (Producción)
- Alpaca API (MOC) & Yahoo Provider (sin Selenium)
- Soporte para `LOCAL_MODE=True/False`
